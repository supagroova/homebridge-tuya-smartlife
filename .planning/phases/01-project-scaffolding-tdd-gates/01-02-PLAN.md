(pnpm + Vitest + SvelteKit) to THIS project (npm + Jest + Homebridge plugin). Wire five hook scripts
into .claude/settings.json (PreToolUse Write test-first guard, PostToolUse Edit|Write

wiring works.

typecheck/lint/format, an 85% coverage Stop gate, an untested-file audit with a debt allowlist, and
a lockfile-drift guard.

wiring, .claude/tdd-debt.txt, Makefile, and one smoke test (src/util/example.{ts,test.ts}).

This is the bootstrap phase that BUILDS these gates, so the harness scripts and config themselves are
EXEMPT from the test-first rule (FND-02 + ROADMAP note). Do NOT TDD the hook scripts. The smoke test
exists only to prove jest + coverage are wired, not to test the harness.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Tampering | package-lock.json drift | mitigate | lockfile-check.sh runs `npm ci` and fails on drift, locally (hook) and in CI (Plan 03), so a hand-edited or transitively-resolved dependency cannot pass silently |
| T-01-04 | Tampering | new jest/ts-jest/@types/jest devDeps | accept | Mainstream, verified-`latest`-pinned test toolchain (STACK.md 2026-06-24); no obscure packages |
| T-01-05 | Repudiation | untested production code slipping in | mitigate | tdd-audit + the PreToolUse test-first guard make untested non-exempt src/ files a hard failure; the exempt list is explicit and auditable |
| T-01-SC | Tampering | npm installs | mitigate | No [ASSUMED]/[SUS] packages this plan; all installs are mainstream toolchain deps. No legitimacy checkpoint required. |
</threat_model>
