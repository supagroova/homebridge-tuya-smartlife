<threat_model>
## Risks

- Accidentally publishing an unverified package or publishing without user intent is irreversible.
- A package can pass tests but omit compiled `dist` files if `files` or build output is wrong.
- Homebridge discovery fails if metadata loses the `homebridge-plugin` keyword or plugin schema.

## Mitigations

- `release:check` validates pack contents and metadata before publish.
- Actual publish remains an explicit external gate.
- Publish workflow uses npm provenance and existing `v*` tag trigger.
</threat_model>
