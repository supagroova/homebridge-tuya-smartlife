<threat_model>
## Risks

- Returning stale values while a Tuya device is offline makes HomeKit appear reliable when the cloud says it is not.
- Letting `onGet` call the cloud can block HomeKit and cause timeouts.
- Updating cache before a write succeeds can drift HomeKit from Tuya after command failures.

## Mitigations

- Offline behavior is unit-tested for every supported binder.
- `onGet` tests use fake cached snapshots and no repository/client mocks.
- Writable binder tests assert command success precedes cache mutation and failures preserve cache.
</threat_model>
