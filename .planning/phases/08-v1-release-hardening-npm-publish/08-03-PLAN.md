<threat_model>
## Risks

- npm publication is irreversible for a version.
- Publishing from a dirty tree can ship unreviewed changes.
- A package can be published but not discoverable by Homebridge if metadata is wrong.
- npm/GitHub auth failures can create a tag without a package.

## Mitigations

- Publish only after explicit confirmation, clean tree, full gate, pack dry-run, and npm identity/version checks.
- Keep release-check tests as the local source of truth for package and workflow invariants.
- Verify the npm package page/version immediately after publish.
</threat_model>
