<objective>
Port the Tuya device-sharing cryptographic primitives with deterministic tests before any network
or QR login work. This plan satisfies AUTH-05 by proving the TypeScript implementation reproduces
the Python SDK's HMAC + AES-GCM `encdata` signing byte-for-byte for known dummy vectors.
</objective>

<threat_model>
## Risks

- Incorrect crypto silently creates unusable tokens or invalid signatures.
- A fixture generated from live traffic could leak refresh tokens or user identifiers.

## Mitigations

- Golden-vector tests use dummy inputs only and run offline.
- Real credential strings, including Home Assistant's `client_id`/`schema`, are not needed in this plan.
- The final verification includes source scans for forbidden credentials and token-like material.
</threat_model>
