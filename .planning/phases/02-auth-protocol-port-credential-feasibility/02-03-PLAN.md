<threat_model>
## Risks

- Local token files could be committed accidentally.
- QR flow code could hard-code temporary credentials while proving the protocol.
- Corrupt token files could crash startup instead of requiring re-auth.

## Mitigations

- `.gitignore` covers local token/probe outputs.
- Credentials are constructor/config inputs only.
- Corrupt persistence behavior is tested and maps to a clear re-auth path.
</threat_model>
