  <name>Task 1: Add dev-only QR probe script</name>
  <action>
    Create `scripts/qr-login.mjs` as a small local tool that imports the built CommonJS auth modules
    from `dist/`. It should require `npm run build` first, read endpoint/user code/client id/schema
    from env vars or CLI flags, print the `tuyaSmart--qrLogin?token=<token>` QR URL, poll for login
    result, and persist tokens through `FileTokenStore` only to a user-selected or ignored local path.
    Add a package script if useful. The script must print a warning that temporary/probe credentials,
    including any HA credential used locally, are never a shipping path.

  </verify>
  <acceptance_criteria>

    - No credential value is hard-coded in the script.
  </acceptance_criteria>
</task>

<threat_model>
## Risks

- Temporary HA credential use could leak into package behavior or docs.
- The project could proceed to device discovery without resolving the credential path.
- Manual probe artifacts could leak secrets through git or npm package contents.

## Mitigations

- Credential scan covers source, package metadata, config, and README.
- `docs/credential-feasibility.md` is a required Phase 2 output and Phase 3 gate.
- `npm pack --dry-run` and `.gitignore` checks prove local artifacts stay out of distribution.
</threat_model>
